## Overview

**KrivX Website** is a modern FinTech-focused website designed and developed for KrivX, an investment guidance and financial services brand.

The website presents investment services, financial products, trading solutions, research-driven guidance, investor support, and the Dhan trading ecosystem through a premium and technology-focused digital experience.

Instead of following a traditional financial-services website style, the interface uses a dark FinTech visual system with blue and green gradients, subtle grid backgrounds, financial dashboard visuals, interactive cards, structured content sections, and modern typography.

The website is built using **HTML5, CSS3, and Vanilla JavaScript**, without relying on a frontend framework.

---

The primary purpose of the KrivX website is to establish a professional digital presence for an investment and financial guidance business while presenting its services in a clear, modern, and visually engaging way.

# UI / UX Design Approach

The website was designed with a strong focus on **visual hierarchy, usability, readability, and modern interaction patterns**.

### Navigation

The main navigation provides access to:

- Home
- About Us
- Why Choose Us?
- Dhan Feature
- Products
- Commitments
- Contact

The active navigation item is highlighted using the KrivX green accent color.

### Visual Hierarchy

Large headings establish section hierarchy while smaller supporting text provides additional information without overwhelming the interface.

### Card-Based UI

Financial features and services are grouped into individual cards so visitors can quickly scan the available information.

### Interactive States

Interactive components use:

- Hover effects
- Border transitions
- Glow effects
- Active states
- Color transitions

These interactions make the website feel more responsive and dynamic.

### Background System

A subtle grid pattern is used throughout the website to reinforce the connection between:

**Finance + Technology + Data**

# How to Run the Website

The project is a static frontend website and does not require a backend server, database, or package installation.

## Method 1 — Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html`.
4. The website will launch in your browser.

## Method 2 — Using Visual Studio Code

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Install the **Live Server** extension.
5. Click **Go Live**.
6. The website will open in your browser.
